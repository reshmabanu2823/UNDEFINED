# UNDEFINED // NULL//ROOT

A futuristic cyberpunk psychological puzzle game built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## 🌌 Project Overview

UNDEFINED simulates a corrupted futuristic operating system terminal. Players interface directly with a compromised quantum neural core to solve psychological puzzles and recover lost memories.

## 🚀 Features

- **Diagnostic Boot Sequence (`NULL//ROOT`)**:
  - Realistic typewriter terminal diagnostic checks
  - Web Audio synthesizer generating real-time mechanical key ticks, warning frequencies, and glitch bursts
  - Corrupted anomaly reveal (`NULL PROCESS FOUND`)
  - Seamless screen transition without page reloads
- **Cyberpunk OS Main Menu**:
  - Interactive command shell (`CONTINUE`, `NEW GAME`, `LOAD GAME`, `SETTINGS`, `EXIT SYSTEM`)
  - Keyboard (<kbd>&uarr;</kbd> / <kbd>&darr;</kbd> / <kbd>Enter</kbd>) and mouse navigation
  - Animated canvas background grid with drifting cyber particles
  - Live command telemetry, hex memory matrix dump, and integrity gauges
  - Visual shutdown sequence with abort/restart capabilities
- **Visual Aesthetic**:
  - Near-black phosphor CRT rasterization (`#05070B`)
  - Electric neon cyan (`#00F0FF`) and hazard red (`#FF2A4D`)
  - JetBrains Mono typography with scanlines, noise textures, and subtle glows

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS + Vanilla CSS CRT shaders
- **Animation**: Framer Motion
- **Sound**: Web Audio API Synthesizer

## 💻 Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
